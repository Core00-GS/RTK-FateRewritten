# 三国逆天改命：文字战略RPG (Three Kingdoms Retro Alt-History RPG)

这是一个以三国时代为背景、精心设计且高度抛光的文字策略扮演（RPG）游戏。玩家将扮演一名起于微末的英雄，通过各种战略选择、武将招募、内政建设、外交博弈以及探索辽阔的华夏神州，逆天改命，重谱历史篇章。

本应用采用了极具国风美学的“古风宣纸”视觉主题（Artistic Calligraphy style），融合了精美的排版和顺畅的交互体验。

---

## 核心系统与功能介绍

### 1. 动态自适应故事主线 (Story Narratives & Custom Paths)
- **多章回体验**: 游戏包含完备的历史演进章节，从“黄巾起义”到“群雄割据”、“官渡、赤壁”，再到“天下三分”或玩家自主称帝。
- **逆天改命多线条分枝**: 在每一个历史关键拐点，玩家需要做出抉择。不仅影响个人属性，也会偏转历史走势（如力挽狂澜拯救关羽、联吴抗曹或自立门户等），改变宿命。
- **自定义英雄建构 (Character Builder)**: 玩家可自定姓名、字号，并合理分配 30 点初始特质点数于武力、智力、统帅、政治、仁德五维属性中，影响游戏内专属抉择的解锁。

### 2. 宏大互动地图探索 (Three Kingdoms Interactive Map)
- **九州重镇巡礼**: 交互式中国古地图，采用 D3.js 节点关系网排布，生动展现涿郡、邺城、北海、洛阳、长安、成都、襄阳、建业等核心地域。
- **行军与探索**: 支持派遣军队或亲率探马在不同地区行军（消耗粮草、黄金或时间），探索未知迷雾区域，解锁地区特有事件、招募地方良将并发现未知宝物。

### 3. 武将名录与 D3.js 属性雷达图 (**全新强化**)
- **群英荟萃**: 拥有庞大的历史武将池（曹操、刘备、孙权、关羽、张飞、诸葛亮、周瑜、赵云、吕布等），每位武将均有其独特的五维特质、专有技能及背景诗词描述。
- **D3.js 属性雷达图 (Radar Chart Visualization)**: **（全新功能）** 在武将详细信息卡片中深度集成了 D3.js 五维矢量属性雷达图。以动态渲染、高对比度的中国风水墨墨圈勾勒武将的“武力”、“智力”、“统战”、“政治”及“仁德”强弱，一眼看清将领独特战术定位。
- **拜访、互动与招募**: 支持在各城镇寻访在野武将，通过赠予黄金、探讨诗书或比武切磋来增进契合度，成功招揽后可为己效力。

### 4. 外交博弈与势力关系 (Faction Diplomacy)
- **诸侯对立体系**: 包含玩家、大汉、曹操、刘备、孙权、黄巾、董卓、匈奴、晋等全势力关系演进面板。
- **多维度互动**: 玩家可通过“修好（赠送礼金）”、“借道”、“联姻”及“宣战”在乱世诸侯间建立同盟、中立或敌对关系，影响势力战事的走向。
- **突发外交随机事件系统 (Diplomacy Random Events)**: **（全新功能）** AI 各大割据势力会根据关系好坏、时间演变，不定期向玩家发起互动，包括：
  - **纳贡/勒索**: 强势势力索要黄金或兵力，顺从能大幅提升友好度，决绝则可能引来大举进犯（关系直降，甚至直接宣战）；
  - **通商贸易**: 远交近攻，势力邀请进行大型战略资源往来，玩家可选择双赢提振经济或拒绝以防通敌；
  - **军事驰援**: 同盟或中立势力在面对外侮（如匈奴或黄巾）时请求主公军队增援，考验玩家兵力运筹的同时极大地重塑阵营格局。

### 5. 领地治理与民生建设 (Territory Governance)
- **内政修缮**: 执掌任一城镇的政务！可选择进行“屯田”以累积军粮、“募兵”以增资部众、“整饬商旅”以征缴税赋。
- **主公才干联动**: 内政产出多寡与主公个人的“政治、智力、统帅”能力值息息相关，展现文韬武略。

### 6. 江湖悬赏与支线任务 (Quest Board)
- **广接悬赏**: 各地官府布告栏随时更新“讨伐流寇”、“赈济灾民”、“护送商队”、“修筑河堤”等多样化支线任务。
- **条件限制与报酬**: 任务对主公的属性（如声望、武力、仁德）设有门槛。完成后可获得黄金、声望、民心、兵员和稀有装备。

### 7. 民间奇遇与运道寻访 (Random Events & Calligraphy Mods)
- **寻访奇遇**: 提供专属的“民间仙道寻访问吉凶”面板，可拜访南华老仙、左慈、管辂等世外高人。
- **博弈属性**: 消耗一定资源（或无代价），即可算乾坤吉凶，增加或衰减主公的个人五维，充满戏剧性。

### 8. 战报史册筛选过滤 (**全新强化**)
- **历史洪流战报 (Battle & Narrative Logs)**: 精心整理的故事行军日志与历史剧变战报，永久记录主公从公元 177 年起，每一天所做出的决定。
- **多维度类型过滤 (Event Filtering)**: **（全新功能）** 新设日志分类筛选面板！点击可在“全部战报（All）”、“行军抉择（Action）”、“军旅伤亡（Casualty）”、“资财增损（Gain）”、“奇遇外交（Random Event）”五大维度之间精准瞬切，方便主公回溯及分析宏观天下格局变动。

### 9. 智能后台自动存档与保存指示 (**全新强化**)
- **免除遗失存档之忧**: 游戏会在后台进行静默的**每 5 分钟定时自动存档（Auto-Save）**，完整将当前的个人属性、武将池、外交关系、任务明细和历史战报写入 `localStorage`。
- **最近保存时间指示器 (Saved Indicator)**: 界面右上角常驻有绿色的高亮中国结徽章式“自动存档指示器”，清晰提供上一次成功持久化保存的具体时间（如 *“最近保存（5分钟内自动）：15:35:01”*），让主公随时掌控战局进展。
- **手动管理功能**: 游戏中同样支持手动一键“封缄史册（手动存档）”、“重开新局（清理存档）”。

## 视觉与交互艺术设计

- **字画轴宣纸底纹**: 主页面底纹设计充满东方宣纸的书信墨香感，辅以暗色红木边框遮罩。
- **高对比排版**: 运用 `Noto Serif SC` 与宋体书体等衬线字形营造浓郁的古典阅读质感。
- **无 AI/API 标识干扰**: 完全屏蔽了一切带有 “Core Node”, “Port: 3000”, “AI Grounding”, “API Error” 等破坏代入感的技术字段与边缘指标，纯正沉浸。

## 技术架构

- 前端：**React 19 + TypeScript + Tailwind CSS 4**
- 动画交互：**motion/react** (原 `framer-motion`)
- 可视化底层：**D3.js** (实现高度客制化的势力网地图及武将属性雷达图)
- 特效与音乐音效：模块化内置合成器与游戏触控音效系统（`src/utils/audio.ts`）
